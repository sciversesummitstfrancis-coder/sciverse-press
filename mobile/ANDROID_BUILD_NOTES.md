# Android build notes — Sciverse Press mobile (Expo SDK 51)

## Status
The mobile app **builds to a real, standalone release APK** with Gradle.
See `../docs/ANDROID_BUILD.md` for the exact procedure and
`../scripts/build-android.sh` for the one-command build.

The APK is produced at:
```
mobile/android/app/build/outputs/apk/release/app-release.apk
```
(and copied to `dist/` by the build script).

## Toolchain (verified)
| Tool | Version | Note |
| --- | --- | --- |
| JDK | **17** | RN 0.74/AGP 8.2 require 17; JDK 21+ fails |
| Android SDK | platforms 35/36, build-tools 34/35/36 | no Android Studio GUI needed |
| Gradle | 8.8 (wrapper) | downloaded automatically |
| Node | 20+ | mobile deps via `npm install` in `mobile/` |

## Env vars
| Var | Purpose | Default |
| --- | --- | --- |
| `EXPO_PUBLIC_API_URL` | REST backend base URL, baked into the JS bundle | `http://localhost:4000` |

> On a physical device, `localhost` is the phone itself. Use your machine's LAN
> IP, e.g. `EXPO_PUBLIC_API_URL=http://192.168.1.8:4000`.
> On an emulator, use `http://10.0.2.2:4000`.

## Commands
```bash
cd mobile

# dev server (Expo Go / Metro)
npx expo start

# standalone release APK (embedded JS bundle, installable anywhere)
../scripts/build-android.sh

# on-device debug build (requires Metro running)
npx expo run:android
```

## Notes
- The `android/` directory is generated by `npx expo prebuild -p android` and is
  safe to regenerate; it is not required to be committed.
- `babel.config.js` includes `react-native-reanimated/plugin` (required because
  `react-native-reanimated` is installed).
- `app.json` sets `android.usesCleartextTraffic = true` so the app can talk to a
  plain-HTTP dev backend on Android 9+.
- Release builds are signed with the React Native debug keystore for
  sideloading. Generate a real keystore before publishing to the Play Store.
